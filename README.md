# IP短视频脚本共创 Lite

这是一套源于**高阶个人 IP 内容方法**、并经过作者实践提炼的轻量化短视频脚本共创 Skill。

它可以从你“想讲的一个话题”开始，逐步引导你明确讲给谁、为什么由你来讲、观众应该记住什么，再把这些判断打磨成一条有个人辨识度、可以直接拍摄发布的短视频脚本。

它不是机械总结信源，也不是输入一句话就直接吐稿的一键写作工具。它的重点是帮助你把内容变成**属于你的 IP 表达**。

## 它的核心价值

你不需要一开始就准备完整选题、完整人设或完整文案。只要有一个想法、一条资讯、一段经历、一个观点，Lite 会带着你完成：

```text
想讲的话题
  ↓
明确讲给谁
  ↓
找到你适合站的位置
  ↓
确定观众要记住的核心表达
  ↓
组织成有个人特色的脚本
  ↓
修改到可以拍摄发布
```

## 它解决什么问题

很多 AI 写稿的问题不是不会写，而是写得太快：

- 信源讲了很多，但不知道真正应该讲哪一个变化
- 内容看起来完整，却没有明确的目标用户
- 语气不像自己，像一篇没有立场的摘要
- 一次生成的稿子不满意，却只能重新开一遍
- 信息很多，但没有一个能让观众记住的核心重点

Lite 把这些关键判断压缩成一条短流程，让你先定方向，再生成文案。

## 核心优势

### 来源于真实 IP 内容学习后的方法沉淀

它不是泛泛的“AI 帮你写文案”提示词，而是从成熟个人 IP 内容方法中提炼出的轻量化共创流程：先确定表达方向，再进入脚本写作。

### 不是机械总结，而是做内容取舍

它会先提炼信源中的事实、变化和待核实信息，再帮助你选择真正值得表达的那一部分。

### 不是替你拍板，而是保留你的表达位置

它会确认你是实践者、观察者、项目负责人、业务顾问还是踩坑者，避免写出“谁都能说、但不像你说的”内容。

### 只确认三个关键判断，速度更快

Lite 只保留最影响成稿质量的三个问题：

1. 这条内容主要讲给谁？
2. 你想以什么身份来讲？
3. 这条内容靠什么取胜？

### 支持自然反馈式修改

你可以直接说“不对”“太泛”“不像我”“换一个角度”，Skill 会保留已经确认的判断，只修改你指出的部分。

### 交付的是完整脚本，不是零散金句

输出包含标题、选题定位、目标用户、创作者角色、核心赌注、表达框架、开头钩子、痛点场景、核心内容、结尾引导和口播备注，可以直接进入拍摄或继续修改。

### 和普通 AI 文案工具的区别

普通工具往往是“给我一个主题，直接写一篇稿子”；这个 Skill 会先帮助你完成关键判断：

| 普通 AI 写稿 | IP短视频脚本共创 Lite |
|---|---|
| 先写再说 | 先确定表达方向，再写脚本 |
| 更像通用摘要 | 更强调你的身份、观点和个人表达 |
| 一次生成，满意与否靠运气 | 可以边沟通边调整，逐步接近你的版本 |
| 输出一段文字 | 输出可以拍摄、可以继续修改的完整脚本 |
| 只处理“写什么” | 同时处理“讲给谁、为什么你来讲、怎么讲” |

## 适合谁

- 想把文章、新闻、论文或产品资料做成短视频的人
- 做抖音、小红书、视频号内容的运营、产品经理和项目负责人
- 有行业经验，但不想写出“AI 味”文案的专业人士
- 想从一个真实案例或工具出发，做出有个人视角内容的人
- 需要快速试多个选题，但又不想每次从零开始的人
- 正在建立个人 IP，希望内容既有信息价值又有“这是我在说”的创作者

## 可以处理什么信源

- 文章和网页链接
- 论文、研究报告和行业资料
- 产品介绍、工具说明和发布信息
- 采访记录、会议内容和个人经历
- 你自己已经有的观点、草稿或零散想法

## 快速开始

```text
根据这篇文章帮我做一个短视频脚本：
{粘贴链接或原文}
```

也可以这样说：

```text
把下面这个产品资料转成适合抖音的选题，先别急着写稿。
```

## 它不做什么

- 不主动寻找或抓取资讯
- 不展开完整版的深层需求追问和完整阶段管理
- 不把没有提供的原文或事实当成已读取内容
- 不替你确认未提供的数字、政策、原话和产品能力
- 不承诺一次生成就一定是最终版本

## 脚本里会有什么

每次交付的脚本通常包含：

- 选题与标题方向
- 目标用户
- 创作者角色与表达位置
- 核心赌注：这条内容靠什么让人记住
- 表达框架
- 前 3 秒钩子
- 痛点或具体场景
- 核心观点、事实和案例
- 结尾引导
- 口播备注与拍摄提示

## Lite 与完整版的区别

Lite 是轻量化、快速上手的 IP 脚本共创版本，适合从一个话题快速走到可发布初稿；完整版会进一步确认主题、深层需求、内容框架、开头结构，并支持更完整的回退和多轮共创。

## 安装

WorkBuddy 或其他支持 Skill 的 Agent：将本目录导入目标 Agent 的 Skill 目录，确保目录内直接包含 `SKILL.md`。

也可以使用同目录的 `content-co-creator-lite.zip`。

安装后，用“根据这篇文章做短视频”“把这个信源变成脚本”等自然语言触发即可。
