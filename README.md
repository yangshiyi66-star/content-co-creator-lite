# 内容共创 Lite

把一篇文章、一个链接或一份产品资料，快速变成一条**更像你、也更容易被人看懂的短视频文案**。

它不是“把原文总结一下”的工具，也不是输入一句话就直接吐稿的一键写作工具。它会先帮你确认：这条内容讲给谁、你站在什么位置讲、观众最后应该记住什么，再把判断转成可发布脚本。

## 它解决什么问题

很多 AI 写稿的问题不是不会写，而是写得太快：

- 信源讲了很多，但不知道真正应该讲哪一个变化
- 内容看起来完整，却没有明确的目标用户
- 语气不像自己，像一篇没有立场的摘要
- 一次生成的稿子不满意，却只能重新开一遍
- 信息很多，但没有一个能让观众记住的核心重点

Lite 把这些关键判断压缩成一条短流程，让你先定方向，再生成文案。

## 核心优势

### 不是机械总结，而是做内容取舍

它会先提炼信源中的事实、变化和待核实信息，再帮助你选择真正值得表达的那一部分。

### 不是替你拍板，而是保留你的表达位置

它会确认你是实践者、观察者、项目负责人、业务顾问还是踩坑者，避免写出“谁都能说、但不像你说的”内容。

### 只确认三个关键判断，速度更快

Lite 只保留最影响成稿质量的三个问题：

1. 这条内容主要讲给谁？
2. 你想以什么身份来讲？
3. 这条内容靠什么取胜？

### 支持自然反馈式修改

你可以直接说“不对”“太泛”“不像我”“换一个角度”，Skill 会保留已经确认的判断，只修改你指出的部分。

### 交付的是完整脚本，不是零散金句

输出包含标题、钩子、痛点场景、核心内容、结尾引导和口播备注，可以直接进入拍摄或继续修改。

## 工作流程

```text
提供信源
  ↓
提炼事实与传播变化
  ↓
确认目标用户、创作者角色、核心赌注
  ↓
推荐一种表达框架
  ↓
生成短视频初稿
  ↓
根据反馈修改
  ↓
确认后输出终稿
```

## 适合谁

- 想把文章、新闻、论文或产品资料做成短视频的人
- 做抖音、小红书、视频号内容的运营、产品经理和项目负责人
- 有行业经验，但不想写出“AI 味”文案的专业人士
- 想从一个真实案例或工具出发，做出有个人视角内容的人
- 需要快速试多个选题，但又不想每次从零开始的人

## 可以处理什么信源

- 文章和网页链接
- 论文、研究报告和行业资料
- 产品介绍、工具说明和发布信息
- 采访记录、会议内容和个人经历
- 你自己已经有的观点、草稿或零散想法

## 输出示例

```markdown
# 视频脚本：{标题}

## 基本信息
- 选题：
- 目标用户：
- 创作者角色：
- 核心赌注：
- 框架：

## 钩子（前 3 秒）

## 痛点场景

## 核心内容

## 结尾引导

## 口播备注
```

## 快速开始

```text
根据这篇文章帮我做一个短视频脚本：
{粘贴链接或原文}
```

也可以这样说：

```text
把下面这个产品资料转成适合抖音的选题，先别急着写稿。
```

## 它不做什么

- 不主动寻找或抓取 AIHOT、网页或其他资讯源
- 不展开完整版的深层需求追问和完整阶段管理
- 不把没有提供的原文或事实当成已读取内容
- 不替你确认未提供的数字、政策、原话和产品能力
- 不承诺一次生成就一定是最终版本

## Lite 与完整版的区别

Lite 适合快速得到一个方向清晰的脚本初稿；完整版会进一步确认主题、深层需求、内容框架、开头结构，并支持更完整的回退和多轮共创。

## 安装

WorkBuddy 或其他支持 Skill 的 Agent：将本目录导入目标 Agent 的 Skill 目录，确保目录内直接包含 `SKILL.md`。

也可以使用同目录的 `content-co-creator-lite.zip`。

安装后，用“根据这篇文章做短视频”“把这个信源变成脚本”等自然语言触发即可。
