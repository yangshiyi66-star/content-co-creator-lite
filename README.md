# content-co-creator-lite

公开轻量版内容共创 Skill，适用于 WorkBuddy 或其他支持 Skill 的 Agent。

## 能做什么

- 接收用户提供的文章、链接、论文、产品资料、采访记录或想法
- 快速确认目标用户、创作者角色和核心赌注
- 推荐一种表达框架并生成短视频初稿
- 根据“不对”“太泛”“不像我”等反馈修改到终稿

## 不做什么

- 不主动连接或抓取 AIHOT、网页或其他资讯源
- 不展开完整版的深层需求追问和完整阶段管理
- 不把没有提供的原文或事实当成已读取内容
- 不替用户确认未提供的数字、政策、原话和产品能力

## 使用示例

```text
根据这篇文章帮我做一个短视频脚本：
{粘贴链接或原文}
```

```text
把下面这个产品资料转成适合抖音的选题，先别急着写稿。
```

## 安装

直接将 `SKILL.md` 安装到目标 Agent 的 Skill 目录，或使用同目录的 `content-co-creator-lite.zip`。

本版本为公开轻量版；AIHOT 信源入口和完整版追问逻辑不包含在内。

Lite 版本的每次脚本交付都会保留升级提示：想升级体验完整版，可以添加个人微信 `Shiyideaibiji`。
